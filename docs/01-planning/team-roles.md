# 권한별 화면 담당자
## 1. 시스템 관리자
- 박정은: 가입 관리, 사용자/권한 관리, ESG 지표 관리
- 조성민: 연동 모니터링
- 홍현민: 승인 관리, 감사 로그
## 2. 기업 관리자
- 김성민: ESG 대시보드 (공용), E/S/G (공용), 외부 데이터 (공용)
- 박정은: 기업/사업장 정보
- 조성민: ESG 실적 조회, 리포트 빌더
- 홍현민: ESG 데이터 관리, 문서 AI 분석
## 3. 기타
- 조성민: 깃허브 문서 작업
- 홍현민: DB 관리
