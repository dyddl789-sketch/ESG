# ESG 프론트엔드 통합 업데이트

## 환경(E)
- 전체 사업장 EMS 원천 데이터 생성 및 월간 수집 시뮬레이션
- 사업장별 전력 사용량 합산
- 공식 전력배출계수 기반 Scope 2 잠정값 계산
- EMS 수집 완료 시 ESG 데이터 관리, 실적 조회, 관리자 대시보드 차트 즉시 갱신
- Redis 분산 락 및 대시보드 캐시 상태 표시
- 사업장별 재수집 시 환경 통계 재계산

## 사회(S)
핵심 지표 4개만 반영했습니다.
- 산업재해율
- 안전교육 이수율
- 위험요인 개선 조치율
- 퇴사율

기능:
- 인사·안전·교육 가상 원천 데이터 생성 및 사업장별 수집
- 4개 지표 자동 계산과 잠정 통계 반영
- 위험요인 AI 유형 분류, 위험도 추천, 개선 조치 초안 생성
- 담당자 검토·확정 후 조치 완료 처리
- 조치 완료 시 위험요인 개선 조치율 재계산
- Redis 수집 락, AI 처리 상태, 사회 대시보드 캐시 표현

## 거버넌스(G)
- 이사회 참석률
- 사외이사 비율
- 윤리교육 이수율
- 그룹웨어·임원명부·교육 데이터 수집
- 이사회 회의록 AI 분석
- 회의 일자, 전체 이사, 참석 이사, 안건 수 추출
- 담당자 확인 후 지표 반영
- Redis 수집 락, AI 분석 상태, 거버넌스 대시보드 캐시 표현

## 공통 흐름
원천 데이터 생성 → 자동 수집 즉시 실행 → 잠정 지표 계산 → 기업 ESG 관리자 검토 → 승인 요청 → 시스템 총괄 관리자 승인·반려 → 승인 완료값만 일반 사용자 공개
